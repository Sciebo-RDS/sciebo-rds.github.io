Class: WebComponent<UserInterfaceType>

Defined in: src/common/web/component/WebComponent.ts:59

Base class for all web components.

By default, an instance of UserInterfaceType is used to create the main UI handler. This can be overriden using the corresponding template and constructor parameters.

Web applications are always based on this class. It mainly maintains an instance of the Core, but also stores general information about the application itself and the entire project.
